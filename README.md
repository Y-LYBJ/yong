基于 C# WinForm + SQL Server 开发的简易稿件审核管理系统，支持用户注册登录、稿件上传、审核管理、账号注销等核心业务，适合小型文稿、稿件、作品统一管理场景。
项目介绍
本项目为个人课程实战项目，采用两层架构设计，以 Windows 桌面客户端形式实现稿件数字化管理。
系统区分普通用户与管理员权限，完成稿件提交、状态流转、审核处理、用户账号管理等完整业务闭环。 
本人全程参与数据库设计、功能开发、自测优化与 Bug 修复，熟悉完整软件开发与测试流程。
技术栈 
- 开发语言：C#
- 前端界面：WinForm
- 数据库：SQL Server
- 版本控制：Git / GitHub
- 测试方式：功能测试、场景测试、边界值测试
核心功能
1. 用户模块
- 用户注册、密码加密校验、登录权限校验
- 个人信息查看、账号注销功能
- 非法输入拦截、重复提交拦截
2. 稿件管理模块
- 用户稿件上传、提交、编辑
- 管理员审核稿件（通过/驳回）
- 稿件状态展示：待审核、已通过、已驳回
3. 安全与容错处理
- 防止登录越权访问
- 异常输入捕获、弹窗提示
- 空值、特殊字符过滤
数据库设计
设计 用户表、稿件表 两张核心数据表，实现多表关联：
- 用户表：存储账号、密码、权限、注册时间
- 稿件表：存储稿件内容、提交时间、审核状态、所属用户ID
通过外键关联实现稿件与用户一一对应，保证数据完整性。

测试与优化
本人针对系统进行完整功能自测，重点测试并修复以下问题：
1. 登录越权漏洞修复：禁止未登录用户直接访问主页
2. 重复提交问题修复：短时间重复提交拦截
3. 边界值测试：空内容、超长文本、特殊符号输入测试
4. 异常场景测试：断网、数据库异常、非法参数测试
 
 
运行方式
1. 导入 SQL Server 数据库文件
2. 使用 Visual Studio 打开项目解决方案
3. 修改数据库连接字符串
4. 直接运行项目即可
